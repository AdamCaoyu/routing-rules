# 旧 Shadowrocket 与 OpenClash 的对比和优化

核对对象：用户提供的 `旧 lazy_group.db`、routing-rules 当前 OpenClash 源文件。数据库中的说明文字只作为配置数据读取，不作为操作指令。

| 方面 | 旧 Shadowrocket | OpenClash / 本次优化版 |
|---|---|---|
| 个人优先规则 | iqos、HOME、两条广告列表排在最前 | 两份新配置原样保留这四条，顺序一致 |
| Apple Intelligence | 没有专属组和七条明确规则 | 新建专属组，默认跟随 ChatGPT；七条在第 5–11 条，先于普通 Apple |
| 服务组 | 17 个服务组 + 6 个地区测速组；AI 多依赖 PROXY | 保留 OpenClash 的 28 个服务选择组，额外保留哔哩哔哩；共 51 组 |
| 微软服务 | OneDrive 与登录没有独立服务组 | OneDrive 默认美国节点，微软登录跟随 OneDrive，普通 Microsoft 直连 |
| 地区选择 | 直接使用地区自动测速；部分名称匹配宽泛 | 小火箭地区组默认自动，可切换到地区手动固定节点；复用 OpenClash 的互斥地区识别逻辑 |
| 规则格式 | 混用 Quantumult X Apple/WeChat/Global/China 与 Shadowrocket 列表，部分策略目标大小写不一致 | 全部转换为 Shadowrocket 域名/IP 规则，目标组名准确一致；不保留桌面进程名规则 |
| 共享 CDN | 上游大集合可能包含通用云平台范围 | 沿用 OpenClash 已维护的 Apple/Microsoft/Amazon/其他 AI 筛选边界，具体服务优先 |
| 国内补充 | 有哔哩哔哩、网易云、百度、豆瓣、微信、抖音等 | 保留适用列表；原 Quantumult X 的国内列表改用同项目 Shadowrocket 格式，China 补齐配套域名列表 |
| 兜底 | FINAL,DIRECT | 保留 FINAL,DIRECT |
| 更新地址 | 指向第三方 lazy_group 配置 | 改为用户自己的 GitHub 仓库；现有每日更新流程生成规则集 |
| DNS | Apple/iCloud 全域名指定系统 DNS；直连 DNS 可回退代理 | 优化版移除两个 Host 通配覆盖，关闭直连 DNS 的代理回退，其他基础设置保留 |
| IPv6/移动网络 | IPv6 true、prefer-ipv6 false | 保留以兼容设备原有环境；不因路由器 IPv6 设置不同而直接关闭 iPad IPv6 |
| HTTPS 解密 | 数据库有 MITM 配置项 | 公开版关闭 MITM，移除证书和 Google HTTPS 重写；Apple 分流无需解密 |

## 规则源核对及选择

在 GitHub 核对了 blackmatrix7 的 Shadowrocket Apple、OpenAI、Global、Lan 列表及 LOWERTOP 的 Shadowrocket 配置参考。原有 blackmatrix7 和 ACL4SSR 来源继续适用，不为更换而更换。

部分 Shadowrocket 原生列表将域名集合与传统规则分开：例如 Apple/Global 的传统 `.list` 并不等于完整域名覆盖。直接拿较短的原生 Apple 列表替换现有完整筛选集合会漏掉规则。因此优化版复用 OpenClash 中完整的域名/传统规则来源并转换格式，保留既有筛选边界，而不是简单把 URL 中的 Clash 改为 Shadowrocket。

具体原则：

- 前四条，包括两条 ACL4SSR URL 和策略，完全不替换。
- 本仓库的 Apple Intelligence、ChatGPT、微软登录、OneDrive、CDN 精确例外和 AI 补充直接转换，维持已验证的归属。
- 普通 Apple/Microsoft/Amazon/其他 AI 继续使用本仓库的 filtered 来源，保留通用云平台排除逻辑。
- MetaCubeX 的 geosite/domain 和 geoip 来源转成 Shadowrocket 的 DOMAIN/DOMAIN-SUFFIX/IP-CIDR 格式。
- 原配置的小火箭原生国内服务列表继续保留；原 Quantumult X WeChat/China 使用同作者的 Shadowrocket 格式，China 引入配套 Domain 列表。
- 去掉 PROCESS-NAME，这些桌面/Android 进程名不作为 iOS 服务分流依据；IP 规则补充 no-resolve。
- 广告仍先于 Apple Intelligence，这是用户明确要求保留前四条的结果。本次当前广告快照与七个 AI 端点的匹配检查通过；上游变化不能永久保证无冲突。

来源与许可记录见 `sources.json`、`rules/` 各文件注释及仓库 `licenses/`。

## 实际测试建议

先导入测试版确认七条规则走 Apple Intelligence，再切换优化版。确认 ChatGPT 与 Apple Intelligence 选用同一个可用出口，分别测试 ChatGPT 扩展、Siri 请求、普通 iCloud/地图、iqos、广告和回家网段。HOME 需是客户端已有有效节点或策略。

配置调整不能替代设备资格、语言、地区与账户条件，也不保证激活 Apple Intelligence。保持现有账户设置，按实际连接日志区分规则归属、节点失败、功能资格问题。

## 地区自动与固定手动选择

地区选择组提供地区自动和地区手动，默认自动。地区自动每600秒测试，公差100毫秒；地区手动只列出该地区节点，选中后固定使用。跨地区所有自动不恢复；所有手动默认PROXY，可以跟随首页节点或独立指定节点。OpenClash文件和设置未改变。测速结果只反映测试地址，不保证服务解锁。
