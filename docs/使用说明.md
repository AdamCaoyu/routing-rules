# 使用与更新

1. 备份当前路由器配置。
2. 在原来的订阅转换编辑页面，将“自定义模板地址”替换为 README 中的新地址；机场订阅和转换后端保持原值。
3. 更新订阅并应用后，核对分组选择。新组名可能没有旧选择缓存；即使旧组名相同，缓存也可能覆盖模板默认。
4. ChatGPT / Claude / Grok / Perplexity / Meta AI 可分别选择出口，不再经过 AI1 / AI2。其他 AI 只接收未被前面专门服务匹配的 AI 域名。
5. OneDrive 的美国节点只是初始选项（该地区默认自动）；微软登录默认跟随它。个人账号可在地区节点卡片内手动选具体节点，登录和文件服务一起跟随。共享微软身份地址也影响其他使用这些地址的微软应用。
6. Apple Intelligence 初始跟随 ChatGPT；若独立选节点，注意 Siri 与 ChatGPT 扩展的出口是否一致。普通 Apple 是另一个组。

Google 组含 Gemini / Google AI 与 Google 登录；Microsoft 组含 Bing / Copilot。它们的共享账号依赖较多，因此目前按账号体系聚合，而 ChatGPT、Claude 等独立服务分别展示。

所有业务卡片只显示策略选项：DIRECT、所有手动、所有自动、香港 / 台湾 / 日本 / 新加坡 / 韩国 / 美国 / 其他节点、REJECT，以及原有的少量共享登录关联。单个服务通常 11 项；没有 AI1 / AI2、组合地区组或长串具体节点。

例如：`OneDrive → 美国节点 → 美国-自动 → 自动挑选美国节点`。在“美国节点”中选具体节点，则该地区组固定使用它；选回“美国-自动”恢复测速选择。所有引用同一地区组的服务都会跟随，不是为每个服务复制一套地区状态。

地区自动组沿用 180 秒检测、100 ms 容差。主选择组中手动指定的节点不会因为辅助自动组重新测速而改变。手动指定节点不可用时会失败，不会擅自换出口；需要自动切换时选回自动。测速只证明测试地址连通，不能保证服务解锁。

空地区的自动组为 REJECT；地区选择卡片仍可见，但没有可用节点时不能使用。不再按下载、备用、公益、耗尽、维护等名称标签排除节点：所有手动和所有自动纳入全部节点，地区组只按地区归类。即使订阅中的流量提示被包装成节点，也不再主动过滤；自动组通过测速判断连通性。

## 节点名称归类

按用户最新更正，先忽略名称开头 `US🔛` / `HK🔛` 等转发标记，再依据后面的节点名称归类：`US🔛…TW台北` 只进台湾，`HK🔛…US王者` 只进美国；普通 `.US王者` 仍归美国。连续多个此类标记也先跳过，不让入口标记干扰分类。

后半名称识别 TW、US、HK、JP、SG 等缩写、中文地名和旗帜；ASCII 缩写设边界，避免 US 匹配到 RUS。UK、RU、TR 等归其他地区。后半名称含多个不同地区或没有可识别地区时不强行分区，仍可在“所有手动”中找到，也可能被“所有自动”选中。

入口是设备先连接的服务器，中转负责转发，出口是最终访问目标网站的服务器。网站通常看到出口 IP。订阅中的箭头和国旗可能来自命名、服务器地址或客户端识别，不能仅凭显示认定真实网络路径；这里按用户确认的名称规则分类，没有实测这些节点的公网出口。

## 从旧版升级

重新转换并更新订阅后，原来服务卡片选“台湾-自动”等选项的，请改选“台湾节点”等新地区卡片。旧的单节点选择也不再是服务组的有效选项；缓存丢失时可能回到默认选择，先核对常用账号服务再使用。

下方“地区-自动”仍保留用于测速，新“地区节点”用于切换自动或手动。模板总计 44 组：28 个服务组、7 个地区选择组、8 个自动组、1 个所有手动组。总卡片数增加了地区控制层，但上层服务卡片不再重复显示整个节点清单。内核自带 GLOBAL 仍会列出节点，不作为日常服务选项。

## 更新规则

关闭 OpenClash“使用规则集”时，规则展开进 YAML，需更新订阅才能更新规则。启用时，兼容后端生成原生 rule-providers，设置每 86400 秒刷新。规则更新并不是实时推送，也不同于机场节点订阅更新。

旧仓库 AdamCaoyu/clash 和旧模板仍可用于回滚。此任务只发布新仓库，没有更改路由器的订阅地址、运行配置或节点选择。

## GLOBAL 与直连兜底

保持 **Rule / 规则模式**。模板最后一条 `MATCH,DIRECT` 才是未命中的直连兜底，即此处所说的黑名单分流。面板的 `GLOBAL` 是内核的全局模式选择器，在规则模式下不决定兜底；切换到 Global 模式再选 DIRECT，会让全局流量直连，而不是按黑名单分流。

## 筛选规则的更新

`rules/filtered/` 保留 blackmatrix7 与 MetaCubeX 的主体规则，只排除审计确认的共享基础设施。GitHub Actions 每天检查一次，也可手动运行；上游不可用、格式异常或条目骤减超过一半时停止发布，保留原文件。GitHub 调度和客户端缓存可能延迟，不能视作实时更新。

本次改了模板中的来源地址，即使已开启 rule-providers，也需要先重新转换并更新一次订阅。只有更新 rule-providers 不会替换旧模板的引用地址。
