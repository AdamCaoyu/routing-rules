# 规则来源与边界

承接此前已验证的个人分流修正，来源为 [AdamCaoyu/clash](https://github.com/AdamCaoyu/clash/tree/fb695eddd60af6a2e79d31715d587ee27d19ad95)，原 Fork 为 [liandu2024/clash](https://github.com/liandu2024/clash)。本仓库重新整理维护入口，不整体复制旧 Fork。

- [blackmatrix7/ios_rule_script](https://github.com/blackmatrix7/ios_rule_script)：普通服务、国内游戏下载、国外集合及 OneDrive 基础规则。含 IP 的来源选用 No_Resolve；Apple 使用 Classical 的筛选版本，Global 保留完整 Classical。
- [MetaCubeX/meta-rules-dat](https://github.com/MetaCubeX/meta-rules-dat)：AI、Disney / Netflix / HBO 和 Netflix IP；动态引用其原生 YAML。
- [Apple 网络要求](https://support.apple.com/en-us/101555)：Apple AI 的 Siri / 搜索 / PCC 地址依据，补充 MetaCubeX 中的精确 Relay。普通 Apple 和 AI 不混为一组。
- [OneDrive 个人版端点](https://learn.microsoft.com/en-us/sharepoint/required-urls-and-ports)与 [Microsoft 365 端点](https://learn.microsoft.com/en-us/microsoft-365/enterprise/urls-and-ip-address-ranges)：个人文件 API、Office 网页、登录和身份资源补充。

规则目录逐条列出引用地址。`rules/local/` 保留来源注释，`rules/clash/` 是同源生成结果，不是第二套独立数据。

具体业务、个人例外和专用 CDN 在前。Amazon 品牌服务与共享 AWS 分开，共享 AWS 归“国外”并置于各服务之后。保留已核对的 Apple / Google CDN 与 AI 前置例外，避免企业综合列表抢先匹配。媒体不整段捕获 AWS 区域，使用专属域名源和少量专用 CDN 补充。

域名规则无法区分同一个登录域名下的不同账号，也无法准确判断所有共享云平台地址属于哪个应用。需要结合实际连接日志处理遗漏。配置检查不等于实际账号、地区资格、UDP、DNS或节点可用性验证。

规则源和数据遵循各上游仓库的许可及使用要求；来源不声明为本仓库原创。

## 2026-10-01 边界复查

- Apple / Microsoft：都移除整个 `akadns.net`；Microsoft 另移除 `b.akamaiedge.net`、`g.akamaiedge.net`、`edgesuite.net`。专用 Apple / Microsoft CDN 条目保留。
- Amazon：从账号服务集合中移除 6 个共享云后缀和 15 条共享 IP 网段；原 Amazon 综合集合后置归“国外”，所以 PayPal、媒体、游戏的专用 AWS 域名仍优先走各自组。
- 其他 AI：移除通用 LiveKit host / turn、Datadog 遥测与 Cloudflare AI Gateway；ChatGPT 专用实时通信端点不变。通用 LiveKit 和 AI Gateway 由后置 Global 承接，通用遥测不强制归 AI。
- 本轮未把所有云平台后缀都清除。Microsoft 中 Azure / Traffic Manager 等仍按微软体系处理，可能服务第三方应用；无法仅靠域名精确识别每个租户。遇到具体日志再加精确例外，避免凭猜测大批删除依赖。

共享性质依据：[AWS CloudFront](https://docs.aws.amazon.com/AmazonCloudFront/latest/DeveloperGuide/Introduction.html)、[Azure Traffic Manager](https://learn.microsoft.com/en-us/azure/traffic-manager/traffic-manager-overview)。原始来源、数量及逐条排除记录见 `rules/filtered/manifest.json`。这次是匹配边界审计，没有宣称逐个验证所有域名的当前所有权或全部账号的实际登录成功。

筛选结果是上游派生数据：AppleServices / MicrosoftServices / AmazonServices 保留 blackmatrix7 的 GPL-2.0 许可，OtherAI 保留 MetaCubeX 的 GPL-3.0 许可；许可全文见 `licenses/`，变更方法公开于 `scripts/sync_sources.py`。
